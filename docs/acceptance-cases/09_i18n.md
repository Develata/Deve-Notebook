## 国际化

```markdown
- case_id: I18N-001
  goal: UI 文本无硬编码。
  preconditions:
    - 前端源码可访问
  steps:
    - run: scripts/check-i18n-hardcoded-baseline.sh
    - run: rg -n "[^\"]+[\u4e00-\u9fa5]" "apps/web/src"  # 检索可见中文硬编码
  assertions:
    - stdout_contains: "i18n-hardcoded-baseline-check: ok"
    - cli_assert: open_tabs_zh_copy_eq "已打开标签页"
    - cli_assert: mobile_toolbar_indent_zh_copy_eq "缩进"
    - stdout_not_contains: ""  # 不应发现硬编码文本

- case_id: I18N-002
  goal: Locale 检测优先级。
  preconditions:
    - ui.locale=auto
  steps:
    - browser_set_language: "zh-CN"
    - browser_reload: true
  assertions:
    - ui_assert: locale_eq "zh-CN"

- case_id: I18N-003
  goal: 不支持的 Locale 回退到 en-US。
  preconditions:
    - 某语言不在当前支持列表
  steps:
    - ui_switch_locale: "xx-XX"
  assertions:
    - ui_assert: locale_fallback_eq "en-US"

- case_id: I18N-004
  goal: 后端返回错误码。
  preconditions:
    - 触发认证错误
  steps:
    - run: curl -s -X POST http://127.0.0.1:3000/api/auth/login -H "content-type: application/json" -d '{"username":"bad","password":"bad"}'
  assertions:
    - stdout_contains: "\"code\":"
    - stdout_not_contains: "密码"

- case_id: I18N-005
  goal: 日期/时间/数字本地化。
  preconditions:
    - 页面展示日期或数值
  steps:
    - run: scripts/check-i18n-formatting-baseline.sh
    - ui_switch_locale: "en-US"
    - ui_capture_text: "date_field"
    - ui_switch_locale: "zh-CN"
    - ui_capture_text: "date_field"
  assertions:
    - stdout_contains: "i18n-formatting-baseline-check: ok"
    - ui_assert: locale_format_changed true

- case_id: I18N-006
  goal: /api/sc/* 返回结构化错误码，而不是裸字符串。
  preconditions:
    - 触发 source control 错误（如提交空 staging）
  steps:
    - run: curl -s -X POST http://127.0.0.1:3000/api/sc/commit -H "content-type: application/json" -d '{"message":"x"}'
  assertions:
    - stdout_contains: "\"code\":"
    - stdout_not_contains: "Nothing to commit"
```
