# 02_positioning.md - 功能定位篇

本章描述当前阶段真实对外提供的产品能力，以及明确不承诺的范围。

## 功能目标

- 用户应能看清当前版本的核心能力是什么。
- 非核心能力不应在界面中被误导成“已经完成”。

## 功能项

### 1. 当前核心能力

- Markdown 编辑与阅读
- Repo / Branch / 文档切换
- Source Control 工作流
- P2P / 同步 / 只读边界
- 登录、会话与基础安全边界

### 2. 当前形态

- 产品是个人部署、个人使用的 Markdown 笔记与协作系统。
- 当前优先级是核心功能稳定，不是扩展能力堆叠。

### 3. 明确非目标

- 默认不把 AI、全文索引、代码执行、复杂媒体处理作为核心必选能力。
- 不把实验性或外围能力伪装成当前主线。

## 非目标

- 当前阶段不承诺“所有高级能力都已完成”。
- 当前阶段不允许插件或显示层主导核心 authority 逻辑。

## Chrome MCP 验收实例

### POS-FEAT-01: 核心能力可达，非核心能力不误导

前置条件：

- 打开应用首页。

步骤：

1. 进入编辑器、Explorer、Source Control、Settings。
2. 观察首页和主工作流中是否突出核心能力。
3. 检查 AI / 插件等外围能力是否被当作主线入口。

期望结果：

- 核心能力可直接触达。
- 非核心能力不会压过 Markdown、Repo、Source Control 等主线。
