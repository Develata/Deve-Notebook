# Source Control External New-File Runtime Smoke - 2026-04-30

## Scope

Validated the browser/server runtime path for an external markdown file created directly under an active local vault.

This smoke covers the path that was not fully exercised by the core regression test:

- `deve_cli serve --dev`
- embedded Web frontend
- WebSocket session and Source Control refresh path
- watcher callback to `FsChangeDetected`
- Source Control HTTP status query

## Environment

- Temporary data root: `/tmp/deve-watcher-smoke-release.LXkoh0`
- Server: `deve_cli serve --dev --port 3104`
- Config overrides:
  - `DEVE_LEDGER_DIR=/tmp/deve-watcher-smoke-release.LXkoh0/ledger`
  - `DEVE_VAULT_PATH=/tmp/deve-watcher-smoke-release.LXkoh0/vault`
- Web asset prep: `NO_COLOR=true trunk build --release`
- Browser: Chrome MCP at `http://127.0.0.1:3104/`

## Result

- Source Control panel started clean for repo `default`.
- Creating `vault/default/smoke/external-runtime.md` produced exactly one visible Added pending entry.
- `fetch('/api/sc/status')` returned one pending row:
  - `path = smoke/external-runtime.md`
  - `status = Added`
  - `doc_id = null`
  - `has_conflict = false`
- Rewriting the same content and then touching the same file did not produce another `Handler: New file detected` log line.
- Browser body did not show rate-limit or refresh-loop text.
- Chrome console had no warning/error messages after rebuilding release dist.

## Notes

The first smoke pass used an old ignored `apps/web/dist` generated by a dev Trunk path and produced unrelated `trunk/ws` console noise. Rebuilding with `trunk build --release` removed the injected Trunk dev websocket script from the embedded assets before the final smoke.

`trunk build --release` emitted one non-blocking Rust warning: `graph_state_attr` is currently unused in `apps/web/src/components/sidebar/source_control/graph_panel.rs`.

## Current Boundary

The runtime smoke confirms the external new-file debounce fix at the browser-visible boundary. It does not yet cover duplicate rename-pair watcher events; that remains a separate watcher hardening task.
